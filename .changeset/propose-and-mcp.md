Add `groundrule propose "<rule>"` to propose a rule for your team to review on the Groundrule platform, and `groundrule mcp`, a Model Context Protocol server (stdio) that lets coding agents list the standards in effect and propose rules when a developer corrects them. New package `@groundrule/mcp`: a dependency-free, tools-only MCP server.
