# RFCs

Changes to the Groundrule document format go through an RFC.

1. Copy `0000-template.md` to `NNNN-short-title.md`.
2. Open a PR. Discussion happens on the PR.
3. Once accepted, implement it in `packages/spec` with tests and a changeset.

| RFC | Title | Status |
|-----|-------|--------|
| [0001](0001-catalog-metadata.md) | Catalog metadata for standards and packs | Accepted |
| [0002](0002-platform-config.md) | Connecting a repository to the Groundrule platform | Accepted |
