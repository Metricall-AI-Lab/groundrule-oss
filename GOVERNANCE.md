# Governance

## Maintainers
Groundrule is maintained by the Groundrule team. Maintainers review and merge contributions and steward the spec.

## Spec changes
The document format (`groundrule.dev/<version>`) changes only through an accepted RFC in [`rfcs/`](rfcs/). Within a version, changes are backward compatible.
