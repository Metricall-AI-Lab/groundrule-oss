# Security Policy

Groundrule reads source code, so we take security reports seriously.

## Reporting a vulnerability
Please **do not open a public issue**. Email **security@groundrule.dev** with:
- a description of the issue and its impact,
- steps to reproduce,
- affected versions.

We aim to acknowledge reports within 2 business days and to share a remediation plan within 7 days.

## Supported versions
Groundrule is pre-1.0. Security fixes land on the latest release.
